Este projeto foi feito para praticar o básico de HTML e CSS!

Usei HTML para estruturar os textos, a imagem e o ícone de carregamento. Utilizando classes para separar cada elemento e deixando o ambiente organizado para aplicar o CSS.

No CSS, coloquei cada elemento no centro da página e usei o "flex-direction: column;" para colocarmos em forma de coluna na página. Com isso, juntamente com gap e text-align, consegui chegar no resultado esperado.

Além disso, no CSS, foi possível adicionar o ícone de carregamento, através do "display:block" e "border" é colocado uma figura quadrada e bordas cinzas na página, contudo, apenas utilizando o border-radius podemos arredondar as bordas deixando-as com a aparência que desejamos, um ícone de carregamento.

Depois, basta trocar as cores de dois lados adjacentes da nossa figura, eu mudei as cores do "bottom" e o "right", mas você pode escolher os lados de sua preferência. Fazendo da maneira certa o resultado será o mesmo.

Para colocar animação é simples.
Adicionei a propriedade de animation: rotate 1s linear infinite; - Dessa forma o navegador entende que a animação de rotação tem duração de 1 segundo, sem aceleração(linear) e infinita. E o bloco de regras @keyframes rotate { to { transform: rotate(1turn); }} para mostrar ao navegador que a animação dará uma volta completa.
